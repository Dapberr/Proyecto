# Sitio web de un centro de FP
---
Este sitio web es de prueba y se usará en clase de Desarrollo de Interfaces web.
Consiste en un sitio web para un centro formativo de FP.

## Tecnologías
- Frontend
    - HTML5 (moderno)
    - CSS3
    - Vanilla JS
- Backend
    - Node.js
    - Express 4.22.3
    - Plantillas EJS

## Arquitectura
- Todo en una única página index, dividido por secciones.

## Contenido de la web
- El contenido debe ser realista.
- El contenido debe estar en ingles.
- Las imagenes por defecto son de picsum.photos

## Conveciones del lenguaje
- Usa ingles para las variables y funciones.

## Limitaciones
- No usar grid
